What was removed, and why

The raw Criteo log has 22 columns. Six never reach either file, and four of those six are dropped because they would give away the answer:

  • uid, campaign — identity rather than signal, and uid would let you memorise users instead of modelling them.
  • conversion_timestamp — when it converted: the label, in disguise.
  • conversion_id — groups the impressions of one conversion: the label again.
  • attribution — Criteo's own last-click flag, nonzero only on converting journeys. The subtlest of the four.
  • cpo — campaign-level cost per order, which leaks the aggregate outcome.

So the only difference between the two files you download is {{ comp.target_column }} itself. The rest were removed before either file was written.

The split boundary is a timestamp quantile taken before subsampling. Subsampling first and splitting second would let a test row predate a train row — the exact failure this competition exists to avoid teaching. You can see it in the preview above: train timestamps start at 4, test starts at 1,848,199.
